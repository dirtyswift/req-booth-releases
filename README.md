# REQ Booth — releases

Binaries only. This repository holds the signed, notarized macOS builds of **REQ Booth**,
the Mac window for [REQ](https://reqdj.com): your track requests land live in a corner of
your screen, above Serato, and you answer without touching your phone.

**Download and instructions: https://reqdj.com/booth**

Each release ships two files:

- `REQ.Booth_<version>_universal.dmg` — what you download and install (macOS 11 or later,
  Apple Silicon and Intel).
- `REQ.Booth.app.tar.gz` — what the in-app updater installs. You never need it yourself.

The source code lives in a private repository. Serato is a trademark of Serato Audio
Research Ltd.; REQ Booth is an independent product, not affiliated with them.
